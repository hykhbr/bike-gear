# bike-gear

> 自行车齿比计算器：算出每一档的齿比，并告诉你这档在什么路况下有用。

骑行时「53×11 到底有多重」「39×32 够不够爬坡」这类问题，凭感觉说不清。齿比是个硬指标：
**牙盘齿数 ÷ 飞轮齿数**，意思是踏一圈，后轮转几圈。把这个数算出来，一整套传动的性格就清楚了。

最初是 Python 入门练习里的几个脚本，后来重构成可复用的模块。

## 功能

- **档位判定**：按齿比区间自动标出超轻 / 轻 / 中 / 重 / 超重档，并给出适用场景
- **全组合矩阵**：牙盘 × 飞轮，一次看完整套传动覆盖了多少个齿比
- **汇总统计**：组合数、最轻档、最重档、齿比跨度
- **CSV 输出**：直接丢进 Excel 画图
- 纯标准库，无第三方依赖，Python 3.9+

## 快速开始

```bash
python gear_ratio.py                            # 默认 53-39 牙盘 + 8 速 11-32 飞轮
python gear_ratio.py -c 50-34 -r 11-32          # 换成压缩盘
python gear_ratio.py -c 53 -r 11-13-15          # 只看单盘
python gear_ratio.py -c 53-39 --csv > out.csv   # CSV 输出
```

齿数用 `-`、`,` 或空格分隔都可以，全角逗号也认。

## 齿比怎么读

齿比数字越大，踩起来越费力、速度越快；越小越省力、爬坡越轻松。

| 齿比 | 档位 | 典型用途 |
|---|---|---|
| < 1.0 | 超轻档 | 陡坡、重载、起步 |
| 1.0 – 1.5 | 轻档 | 缓坡、逆风、休闲骑 |
| 1.5 – 2.5 | 中档 | 平路巡航、团骑 |
| 2.5 – 3.5 | 重档 | 提速、顺风、下坡 |
| > 3.5 | 超重档 | 冲刺、极速下坡 |

**齿比跨度** = 最重齿比 ÷ 最轻齿比，衡量一套传动够不够「全能」，公路车通常 3.5–4.5 倍。
